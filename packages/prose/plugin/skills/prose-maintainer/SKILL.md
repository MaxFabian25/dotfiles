# Prose maintainer

Work in `packages/prose` in the [dotfiles repository](https://github.com/MaxFabian25/dotfiles),
not in an installed copy. Locate that checkout through the device's dotfiles configuration.
Read `packages/prose/CONTRIBUTING.md` for editing, verification, and release instructions.
Apply the requested change there and complete the relevant checks.
