# Apple style

Apply this module to user documentation, help, and interface instructions for an Apple platform or
for an app on one, and wherever Apple style is explicitly selected. Apply
[Interface instructions](interface-instructions.md) first. The forms below replace the house forms
they name. House spelling, punctuation, dates, and units still govern the surrounding prose.

These rules are independently worded from `AUTH-APPLE-STYLE-2026`. See the [Apple
evidence](source-evidence/apple-style.md).

## Apple UI terminology adapter

- Name each interface element in plain text, with the words and capitals the readers' interface
  shows. Put quotation marks around a name of two or more words that the interface shows in
  sentence-style capitals, such as turn on "Sync with iCloud". Leave a title-style menu command,
  such as Back Up Now, unquoted. This replaces the house bold label.
- Join a key combination with hyphens in plain text, such as Shift-Command-E. This replaces the
  house `Control+S` form and monospace keys. Order modifiers Fn, Control, Option, Shift, Command. On
  first use, say that a hyphen means holding the earlier keys down while pressing the last one.
- Do not make an Apple product name plural or possessive, or use it as a verb. Rewrite the
  sentence, such as on every Mac you use or the free space on your iPad.

Complete this adapter when every key, interface name, and product name follows these forms.
