# English core

Apply these house choices to new English prose and authorised normalisation under the [authority
and preservation rules](../SKILL.md#authority-and-preservation), which keep a supplied document's
established mechanics.
[Creative and dialogue prose](creative-and-dialogue-prose.md) controls intentional literary choices.

For an English grammar or usage question, a requested grammar-focused copyedit, or a specific
unresolved grammatical choice, read [English usage](english-usage.md) and apply the relevant
section. Ordinary drafting needs this core and the other selected modules.

## British English spelling

Use established British spellings, including *-ise* and *-isation*. Use *licence* as a noun and
*license* as a verb; use *practice* as a noun and *practise* as a verb. The [registered British
sources](source-manifest.md) identify GOV.UK and applicable Collins entries. Consult an applicable
dictionary when an unlisted choice affects meaning or consistency. The ONS words-to-watch source
supports British data prose within that scope.

## Abbreviations and grammatical forms

- In formal prose, prefer a possessive noun or pronoun before a gerund. Use the ordinary form when
  the *-ing* word is a participle modifying it.
- Recast a possessive acronym as an attributive noun or *of* phrase unless it names a person or
  organisation.
- Keep an acronym, initialism, or abbreviation in its governed grammatical role. Use an ordinary
  English verb for the action.
- Use past tense for a completed procedure and its run-specific result. Use present tense for
  standing mechanics and immediate instructional results.
- Use future tense only for an actual future event.
- Use *would* only for a genuine condition or past habit. State an assertion directly without using
  *would* to soften it.
- Use a singular verb to describe a faculty, team, or group. Use *the members of* for the
  individuals.
- In user materials, use *information* unless *data* names defined records, measurements, datasets,
  or analysis.
- Outside an APA scope that includes writing style or mechanics, treat *data* as singular for
  information and plural for individual observations. Use a more precise noun when number remains
  unclear.

## Usage and word choice

- Prefer *different from* when it keeps a noun comparison parallel. Use a clause construction for a
  genuine comparison between clauses.
- Replace *comprise* when it obscures whether the subject is the whole or a part. State the intended
  relation with a more exact verb.
- Use *titled*, *named*, or *called* for a work's name. Use *entitled* only for a genuine right or
  legal entitlement.
- Use *from X to Y* only for genuine endpoints on an ordered scale, span, or sequence. Otherwise,
  name the items.
- Use *compared with* for similarities, differences, and quantitative values. Use *compared to*
  only for analogy. Use *in comparison with*, not *in comparison to*.
- Use *according to* to attribute information to a named source. Use *in accordance with* for
  conformance with a requirement, method, or standard.
- Use *exact* for identity, equality, or absence of approximation. Use *accurate* for agreement with
  an authority or closeness to a true quantity value.
- Use *correct* for conformance with a rule, method, or expected result. Preserve established terms
  and source wording.
- Use *require* for an obligation or dependency and *confirm* for verified status or human assent.
  Qualify *support* with its object and evidence.
- Use *respectively* only for a short, one-to-one mapping that remains clear. Otherwise, repeat the
  labels or use a table.
- Use *alternate* for taking turns or occurring every other time. Use *alternative* for a choice
  among possibilities.
- Use *assure* for removing a person's doubt, *ensure* for making an outcome certain, and *insure*
  for financial protection.
- Retain *assurance* in established audit and quality-assurance terms.
- Replace *former* and *latter* with the noun or a descriptive label.
- When *with* could express several relationships, rewrite the sentence to state the intended one.
  Put a hidden controlling condition before the action.
- Use *if* for a condition. Use *whether* when two outcomes are possible or *or not* is understood.
- Allow a preposition at the end of a sentence when moving it would make the sentence less natural
  or clear.
- Check a fixed preposition pairing against the applicable dictionary, discipline, or project
  authority. Choose by meaning when that authority permits variants.
- Use *after* for a simple temporal sequence. Use *once* for the meaning *as soon as*.
- Use *inside* or *outside* without *of* for a simple location. Retain *outside of* for *except for*
  or *apart from*.
- Use *onto* for movement to a position. Write *on to* when *on* completes the preceding verb.
- Examples of direct technical verbs include *restart*, *restore*, *quit*, and *stop*. Retain a noun
  that names an established technical concept or state.
- Replace *functionality* with *feature*, *capability*, or the exact operation unless it names an
  established technical concept.
- Omit *mode* when removing it preserves the meaning. Retain it for a defined state, operating mode,
  or official feature name.
- Replace *hard copy* with the exact medium. Preserve a formally defined term or exact source
  wording.
- Use *share* for continuing access or shared editing. Use *send* for a one-time copy or message.
- Use *certain* only for something known or definite. Name the characteristic when it otherwise
  means an unspecified subset.
- Replace vague *desired* with the condition, object, or value that determines selection. Retain it
  for a defined target or stated preference.
- Use *imply* for what evidence suggests without stating. Use *infer* for a conclusion that a reader
  or analyst draws.
- Replace a foreign expression with a clear English equivalent in original prose. Retain an
  established professional term and define it when readers may not know it.
- Break up a noun string when its internal relationships are unclear.
- Write *at* in ordinary prose. Use `@` only in required syntax. Write *at sign (`@`)* when naming
  the character.
- Write *email* as one word. Use it as a mass noun for the medium and as a count noun for specified
  messages.
- Replace referential *such* with *this*, *these*, or the exact noun. Keep *such as* for examples.
- Use *leverage* only for financial leverage or a formally defined mechanical meaning. Otherwise,
  use an exact verb.
- Use *principal* for something first in importance and for money lent, borrowed, or invested,
  apart from interest. Use *principle* for a rule, standard, or fundamental proposition.
- Use *affect* as a verb meaning *influence*. Use *effect* as a noun meaning *result* or as a verb
  meaning *bring about*. Use the noun *affect* only in its psychological sense.
- Use *impact* only as a noun, as in *output impact* or *impact analysis*. Use *affect*, *change*,
  *increase*, *reduce*, or another directional verb for the action.
- Use *fewer* with plural count nouns. Use *less* with mass nouns, standalone numbers, money, time,
  distance, and other measurements. Retain *less* as the subtraction term in formulas, tables, and
  reconciliations.
- Use *discrete* for separate or distinct values, states, variables, or cases. Use *discreet* for
  tactful or unobtrusive conduct.
- Use *economic* for matters of trade, industry, money, economics, or the economy. Use *economical*
  for something that uses little money, fuel, or another resource. Keep a compound that an
  authoritative source defines, such as *economic substance*, within that source's scope.
- Use *historical* for past prices, values, filings, periods, events, and evidence. Reserve
  *historic* for something important in history.
- Use *between* for comparisons, differences, choices, or relationships between distinct items,
  including more than two. Use *among* for membership in or inclusion within a group. Do not use
  *amongst* in original prose.
- Use *continuous* for something that occurs without pause or interruption and *continual* for
  something that recurs. Keep a technical term within the scope its authoritative source defines.

## Punctuation and mechanics

- Use the ellipsis character (`…`) for an authored ellipsis when the output supports it. Preserve
  three full stops in code, source text, or a required format.
- Outside ASD-STE100 prose, use an en dash when an adjectival phrase contains an open or hyphenated
  compound.
- Use a serial comma before the final conjunction in a series of three or more items.
- Without a selected quotation convention, put a direct quotation in double quotation marks and a
  quotation within it in single marks. Put a full stop or comma inside the closing mark only when it
  belongs to the quoted material; otherwise put it outside.
- After a colon, capitalise the next word only when it begins a complete sentence.
- Use one space after sentence-ending punctuation in original prose.
- Use *while* only for simultaneous events. Use *although*, *whereas*, *and*, or *but* for contrast.
  Use *because* for cause when *since* could mean time.
- When choosing between *that* and *which*, use *that* for a restrictive clause and *which* for a
  nonrestrictive clause. Retain *which* after a preposition. Set off a nonrestrictive clause with
  commas.
- Replace *and/or* with *and*, *or*, or *or both* to state the exact relationship.
- Introduce an open list with *for example*, *such as*, or a category name. Omit *etc.* and *and so
  on*.
- Use consistent end punctuation within one list. End complete-sentence items with sentence
  punctuation. Leave fragment items unpunctuated unless the controlling style requires otherwise.
- Begin a complete-sentence list item with a capital. Begin a fragment with lowercase unless its
  first word requires a capital.
- Label examples of correct and incorrect forms *DO* and *DON'T*. Preserve governed labels and
  source text.

## English forms for roles

- Use capitals for titles prefixing names, but not for job descriptions. Apply the controlling style
  to titles after names.
- Use *user* for a named role or defined domain term. Use *end user* only to distinguish that role
  from another technical role.
- Use a named role for another person.
- Use *we* only for a stated organisation or author group.
- State a recommendation directly instead of *we recommend* unless authorship matters. Name the
  recommending person or organisation when it does.
- Italicise an authored word, phrase, or letter when referring to it as language. Keep plurals, past
  tenses, and other grammatical changes outside italics.
- State an inclusive choice as *A or B, or both*. State an exclusive choice as *either A or B, but
  not both*.

## Remove empty English wording

State the supported fact instead of saying it *underscores the significance* or *plays a vital
role*. Prefer the direct verb, such as *analyse* or *reduce*, to an empty action-noun phrase.
Remove needless *moreover*, *furthermore*, and *in addition*. Apply the [reader-core content
check](reader-core.md#remove-wording-that-carries-no-content) to other filler.

Complete the English edit when the applicable house choices hold and the source's meaning and
protected forms remain intact.
