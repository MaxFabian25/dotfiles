# Quantitative prose

Apply this branch when equations, quantities, units, numerical comparisons, or statistical claims
are present. Apply the [authority and preservation rules](../SKILL.md#authority-and-preservation)
before changing source notation, machine syntax, identifiers, or governed labels.

Use the registered UK Analysis Function and ONS authorities for analytical prose, statistical
language, and causal restraint. Apply `AUTH-OSR-CODE-3` only to public communication of statistics,
data, or wider analysis. Apply `AUTH-NIST-SP330` only when United States federal scope controls.

## Equations and notation

- **Formula inclusion.** Include a formula only when it is new, uncommon, or essential to
  understanding or reproducing the analysis. Otherwise, name the standard method.
- **Mathematical and unit symbols.** Define each non-standard symbol when first used. Keep its meaning unchanged within the document. Use standard quantity, unit, and mathematical symbols when they exist. Do not add a plural ending to a unit symbol. Add a full stop only when it ends the sentence.
- **Operators and variables.** Apply the selected mathematical or document convention. Otherwise,
  italicise algebraic variables. Keep operators, numerals, punctuation, unit symbols, and
  non-variable abbreviations upright.
- **Operator spacing.** Put spaces around binary operators. Put no space after a unary minus or
  between a base and its exponent or subscript. Use non-breaking spacing when the output must remain
  on one line and the host supports it.
- **Exponents and subscripts.** Render exponents and subscripts with host-supported formatting. Do
  not use a caret in reader-facing notation unless a governed or exact syntax requires it.
- **Expressions and equations.** Keep a short expression or equation inline. Put it on its own line
  when an awkward line break or its complexity would obstruct reading. Use words when notation would make the sentence ambiguous,
  ungrammatical, or difficult to read.
- **Mathematical symbols.** Use the host-supported character, entity, or mathematical rendering for each
  symbol. Verify the rendered symbol and its accessible reading. Do not substitute a lookalike
  keyboard character.
- **Equation context.** Place each displayed equation in a sentence or introduce it with a complete sentence. Define its variables in nearby prose. Give a text explanation when notation alone does not convey its purpose.
- **Formula punctuation.** Treat an inline or displayed formula as part of its sentence. Put sentence
  punctuation after the formula when the sentence requires it. Keep punctuation inside mathematical
  notation only when it belongs to that notation.

## Comparisons and statistical claims

- **Numerical precision.** For reader-facing output, display no more precision than the source data and the reader's decision require. Use the same decimal precision for comparable values in one column. Keep enough precision in calculations to avoid rounding error. Disclose material rounding when displayed components no longer sum to the displayed total.
- **Percentages and percentage points.** Use *percentage points* for the arithmetic difference between two percentages. Use *per cent* or `%` for a change relative to the starting value. State the starting value when the distinction might not be clear.
- **Changes and multiples.** Use *from A to B* for endpoints, *by Δ* for the amount changed, and
  *to B* for the ending level. Express a multiple as *B was X times A* or *increased to X times A*.
- **Quantity comparisons.** In running prose, use *more than*, *less than*, or *fewer than*. Reserve
  *over* and *under* for non-quantity meanings. Use inequality symbols only in formal notation.
- **Figure status.** When a figure is not an actual value, label it with its status. Examples include
  *estimate*, *forecast*, *assumption*, *target*, *provisional*, and *illustrative*. Put the label
  next to the figure or series.
- **Complete comparisons.** In each quantitative comparison, identify the measure, comparator or baseline, and the period when time bounds the values. Compare like with like. If definitions, scope, or methods differ, state the difference before you draw a conclusion.
- **Causal language.** Use a causal verb only when the evidence supports a causal claim. Otherwise, describe the association, difference, sequence, or prediction that the evidence establishes.
- **Currency.** Identify the currency whenever a monetary amount could be mistaken for another
  currency. In English prose, put a currency symbol directly before the numeral. In Danish prose,
  follow the locale form, with the amount first and a space before the symbol or abbreviation, as
  in `100 kr.` When several currencies appear in one context, identify each amount with its
  three-letter ISO 4217 currency code, written before the amount with a space, as in `USD 120`.
- **Statistical significance.** In a statistical context, reserve *significant* for the phrase *statistically significant*.
- **Robustness claims.** Use *robust* for a statistical estimate, test, or analysis only when a
  named test or sensitivity analysis supports the term. State that support in the prose unit or a
  cited display. Otherwise, state the tested property.

## Quantities and units

- **Precise quantities.** Write a precise or negative quantity as a numeral, including values below
  10. A precise quantity is a value with a unit of measurement, a sum of money, a percentage,
  ratio, or rate, or a statistic. Treat a duration or age in calendar units, such as days or years,
  as a count unless a selected convention treats it as a quantity. [Number
  forms](number-forms.md#number-words-and-ordinals) owns plain counts.
- **Unit symbols and numerals.** In running prose, use a unit symbol only with a numeral. Spell out
  a unit named without a value.
- **When to spell out.** In non-APA user documentation, spell out an unfamiliar unit of measure on
  first occurrence. Give its unit symbol or abbreviation in parentheses. Repeat it in new sections
  and chapters when its unit symbol or abbreviation is obscure to readers.
- Spell out non-SI units of measure in text unless a higher authority requires another form. Unit
  symbols or abbreviations may appear in tables and technical specifications.
- **Unit names, symbols, and prefixes.** Follow the standard capitalisation and form of every unit
  name, unit symbol, and abbreviation. Do not mix unit symbols and names. Join a prefix name to a
  unit name and a prefix symbol to a unit symbol. Use only standard unit symbols and abbreviations.
  When a spelled-out unit of measure forms a compound adjective, follow the selected language's
  hyphenation rules.

## Terminology

| Scope | Preferred designation |
| --- | --- |
| Property expressible by a number and reference | quantity |
| Letter or sign that denotes a unit | unit symbol |
| Arithmetic difference between two percentages | percentage point |
| Reference quantity used in a measurement system | unit |
| Number and reference that together express a quantity | quantity value |
| Change relative to a starting value, expressed as a percentage | percentage change |
| A survey-estimate difference that exceeds the stated statistical-significance threshold | statistically significant |
| Desired future level against which performance is measured | target |
| Expected future performance of a business | forecast |
| Statistical or analytical value that carries stated uncertainty | estimate |

Complete this branch when each equation, quantity, comparison, statistic, status, and unit states
its meaning and follows the governing evidence and notation.
