# English document prose

Apply this branch to original English prose in a durable document with structural divisions. Start
by identifying its authored titles, headings, cross-references, appendices, and named roles.

- Introduce related subsections with *the following sections*, not *this section* or *these
  sections*.
- Pair *above*, *below*, *earlier*, or *later* with the named cross-reference target.
- Write link text under [Link selection and behaviour](references-and-citations.md#link-selection-and-behaviour).
- A table *shows*, a model *assumes*, a system *detects*, and a section *sets out*. Use comparable
  functional verbs for other inanimate subjects.
- Use *Appendix* for one appendix and *appendices* as the British plural. Label multiple appendices
  consistently.
- Use lowercase for common terms. Retain capitals for proper names, official titles, governed
  labels, and required forms.
- Use sentence case for authored titles and headings unless another selected style controls.
- End an authored title or heading without a full stop. Retain a meaningful question mark.
- Omit authored exclamation marks from documentation unless necessary dialogue requires them.
  Preserve quotations, official titles, and exact interface literals.

Complete this branch when every English structural label, title, heading, cross-reference,
appendix, and role uses the selected form consistently.
