# IBCS source evidence

## IBCS Standards

The [IBCS notation module](../ibcs-notation.md) adapts selected notation rules for text elements
from sections SI 5.2, UN 1.2, UN 2.2, UN 2.5, UN 3.2, UN 3.3, and UN 4.1. It contains independently
worded adaptations and exact source designations, such as AC, ΔPL, and mEUR. It does not reproduce
the standard. The checked copy is the printing dated 2026-07-02, ISBN 978-3-9821414-4-2, published
under the Creative Commons Attribution-ShareAlike 4.0 International licence. The standard aligns
its notation with ISO 24896, whose text Prose has not reviewed. The [IBCS
charts](../../../charts/references/ibcs-charts.md) module in the charts skill adapts visual notation
from sections SI 3.1, SI 5.2, UN 2.3, UN 3.2, UN 4.1, EX 1.1, CH 4.1, and CO 4.2 in the same
independently worded way. The full chart-selection matrix and the other composition principles lie
outside both modules.
