# Plain-language source evidence

## Plain language

The skill uses publicly described principles and terminology from these standards. It does not
reproduce licensed normative text or claim conformity.

ISO 24495-3 supplies the scope of plain science writing: explaining scientific subjects to readers
with varying education levels, backgrounds, or interests. It supplements ISO 24495-1. It does not
replace a selected document standard or govern specialist scientific writing. The Authority
Register owns each standard's edition and maturity; the Terminology Register owns the designation.

### Supporting plain-language literature

These sources support independently worded rules about reader needs, information order,
definitions, testing, uncertainty, visual explanation, and scientific communication. Digital.gov's
plain-language guide carries forward selected PlainLanguage.gov guidance. The archived
[PlainLanguage.gov repository](https://github.com/GSA/plainlanguage.gov) retains the retired site's
pages under the CC0 1.0 public domain dedication.

The SEC's *A Plain English Handbook* supports the rules on drafting labels, summarised provisions,
and worked examples for financial or contractual mechanisms.
The handbook declares itself uncopyrighted, but its preface, margin quotations, and Appendix B
filings are third-party material, so Prose uses independently worded rules and reproduces none of
it.
