# Diátaxis source evidence

## Diátaxis

The start page supplies the four source designations and their user-need mapping. The type pages
supply the selected principles for tutorials, how-to guides, reference, and explanation. The
compass supplies the two classification questions.

The registered term locations are [the four kinds of
documentation](https://diataxis.fr/start-here/#the-four-kinds-of-documentation),
[tutorials](https://diataxis.fr/start-here/#tutorials), [how-to
guides](https://diataxis.fr/start-here/#how-to-guides),
[reference](https://diataxis.fr/start-here/#reference), and
[explanation](https://diataxis.fr/start-here/#explanation).

The [Diátaxis module](../diataxis.md) contains independently worded adaptations. It reproduces no
diagram or extended source text and does not require a Diátaxis-labelled navigation structure.
