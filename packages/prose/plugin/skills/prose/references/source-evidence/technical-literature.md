# Technical source evidence

## Supporting technical literature

ISO 704 supports the distinction among concepts, definitions, and designations. ISO 30042 supplies
the termbase exchange model. ISO 24183 supplies terminology for technical-communication
information products.

The W3C article defines localisation and internationalisation for product, application, or document
content. It identifies address and contact information formats and script-specific readability
requirements. It also describes design and development practices that enable localisation.

Prose independently adapts the Microsoft guide's error and status-message guidance within its
Windows Admin Center scope. The guide does not establish a general taxonomy of software
messages.
