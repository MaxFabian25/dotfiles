# Creative and dialogue prose

Apply this branch to original or edited English creative, literary, or dialogue prose. It also
covers a narrator's or character's intentional dialect, code-switching, and established voice.

This branch is more specific than general sentence-shape, register, idiom, and punctuation
preferences. Apply those preferences only when they do not flatten intentional voice. The
ASD-STE100 branch does not apply.

## Editorial discretion

Treat intentional dialect, dialogue, code-switching, and established voice as literary choices.
Follow the [authorised editing scope](../SKILL.md#authority-and-preservation). During copyediting,
change deliberate literary choices only when the user explicitly authorises the change.

## Dialogue mechanics

- Start a new paragraph when the speaker changes.
- Keep one speaker's dialogue and directly related action in the same paragraph.
- Use a speech tag only when a speaking verb attributes the words. Join it using the selected
  dialogue punctuation. Without a selected convention, put the comma or end punctuation that closes
  or joins spoken words inside the closing mark.
- Treat an independent action as its own sentence. Do not punctuate it as a speech tag.
- For speech spanning paragraphs, start each paragraph with an opening quotation mark. Add the
  closing mark only when that speaker's speech ends.
- Use an em dash for an abrupt cutoff or interruption. Use an ellipsis when speech trails away or
  falters.
- Show a stutter with the fewest repeated sounds needed to establish it.
- Permit fragments, contractions, idiom, semicolons, and em dashes when they serve narrator or
  character voice.
- Apply the selected quotation convention when it requires different marks or placement.

Complete this branch when the edited passage preserves intentional voice, dialect, character
identity, and narrative function. Keep discretionary changes within the authorised editing scope.
