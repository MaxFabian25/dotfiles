# Commits and pull requests

Apply this branch to newly written or reactivated commit and pull request text. Leave existing history and merged pull request descriptions unchanged.

Write commit messages and pull request text in English. Use Danish only for quoted content or a term that the applicable project-specific skill defines.

Write each commit subject and pull request title as one imperative English sentence without a type prefix or closing full stop. Leave a blank line between a commit subject and its body.

| Scope | Preferred designation |
| --- | --- |
| First line of a commit message | commit subject |
| Human-facing title of a pull request | pull request title |
| Explanatory text of a pull request | pull request description |

Complete this branch when the requested commit or pull-request components identify the change.
Include the reason, supporting evidence, and required reader action where the requested component
needs them. Keep a subject-only or title-only request within that scope.
