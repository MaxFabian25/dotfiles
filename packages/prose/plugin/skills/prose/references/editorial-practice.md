# Editorial practice

Apply this branch when supplied prose is edited or reviewed, when you revise your own draft after
feedback, or when a voice sample guides new prose.
Use the request and prior decisions to determine the authorised editing scope, including
permission to normalise the prose.

When the user requests copyediting for a named defect, change only text that carries it. When the
user requests a review without edits, report findings without changing files. For a consistency
review, use the [document-level checks](editorial-verification.md#document-level-checks) as review
criteria. Distinguish an error or inconsistency from a discretionary style choice. Raise an issue
beyond the authorised scope without editing it.

When reviewing a whole piece, lead with any problem that most limits its purpose, then order
passage-level findings by their effect on the reader.

Query uncertainty that would materially affect meaning, factual basis, voice, or scope. Write
neutral, concise, answerable queries and offer concrete alternatives when known. Use prior answers
and decisions.

Treat each cut or correction the user makes, and any reason they give, as a standing rule for the
rest of the work. Apply it in one pass to every remaining item and to each companion document, and
list the further changes it implies for one confirmation instead of asking about each item. Once the
user has said a piece is too long, make later fixes replace words rather than add them.

## Voice samples

Use a sample supplied for voice matching to guide vocabulary, rhythm, punctuation, and formality
within the authorised style scope. Its events, opinions, and experiences belong to that sample;
include them in the new piece only when the user also supplies them as source material for it.

## Manuscript workflows

When the project uses formal manuscript stages, apply its agreed editing level for each pass:

| Level | Permitted focus |
| --- | --- |
| Developmental editing | Content, presentation, documentation needs, and extensive rewriting or reorganisation |
| Line editing | Word choice, phrasing, and writing style at sentence level |
| Copyediting | Preparation of an otherwise final manuscript for publication through approved mechanical editing and, where needed, substantive editing |
| Proofreading | Remaining errors after the manuscript has been typeset or converted for publication but before it is published |

Within copyediting, distinguish mechanical editing from any agreed substantive editing.
Mechanical editing applies the selected style consistently to the text, documentation,
tables, and illustrations and checks grammar, syntax, and usage. Substantive editing addresses the
organisation and presentation of existing content.

When the editorial process designates the author's review as the last opportunity for substantive
changes, honour that cutoff. After it, make only changes permitted by the current stage or approved
by the governing authority. At handoff, give each unresolved query an owner and status.

## Sensitivity and authenticity readings

When a sensitivity or authenticity reading applies, record its purpose and the reader's special
knowledge. Ask the reader to identify inappropriate or harmful material or inaccurate content
outside the author's direct personal experience. Record each suggestion as a query rather than an
edit. Route each recommendation to the author or governing authority for decision. Run legal,
technical, and accessibility conformance review separately when those authorities apply.

Give each suggestion an answer, decision, or recorded owner and status.
