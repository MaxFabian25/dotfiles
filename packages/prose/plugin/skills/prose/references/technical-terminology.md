# Technical terminology

Apply this branch when choosing, defining, translating, or verifying a technical or professional
designation in the subject fields below. A mention of technical terminology in another claim does
not select this branch. Keep each term within its authority's subject field and scope.

## Evaluation and assurance

| Scope | Preferred designation |
| --- | --- |
| NASA review of system progress and maturity against defined entrance and success criteria | technical review |
| Direct examination of an observable product or state | inspection |
| Product satisfaction of specified requirements | verification |
| Product satisfaction of intended use and user needs in its intended environment | validation |
| Untrusted input satisfaction of a syntactic and semantic input contract | input validation |
| Fulfilment of a requirement | conformity |
| Meeting all of an organisation's compliance obligations | compliance |

## Information removal

- *media sanitization*: process that renders target data infeasible to access for a stated level of effort.

When a system removes data or a resource from active use, describe that action directly.
Claim media sanitization only when the applicable NIST process was performed.

## Permission and results

| Scope | Preferred designation |
| --- | --- |
| Permission expressed by an ISO or IEC document | may |
| Possibility or capability in an ISO or IEC document | can |
| Any output, outcome, or impact of an intervention | result |
| Short- or medium-term effects of an intervention's outputs | outcome |

The ISO/IEC verbal forms govern ISO and IEC documents. Outside that scope, apply [Requirement
language](instructional-prose.md#requirement-language) to *may* and *can*.

## Code-adjacent terminology

For *code span*, use [Literal formatting](technical-and-code-prose.md#literal-formatting). For
*comment*, use [Code comments](technical-and-code-prose.md#code-comments).

Complete this branch when every selected term matches the authority, subject field, concept, and stated scope.
