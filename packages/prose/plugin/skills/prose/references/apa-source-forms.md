# APA source forms and generative AI

Apply this branch alongside [APA citations and references](apa-citations-and-references.md) when
selecting a specific APA reference-entry form (including financial filings, press releases, slides,
earnings calls, databases, and software) or citing generative AI tools and output.

## Source forms

Classify a source by what it is, not by how you retrieved it. A report or press release found on a
website takes its own form; use the webpage form only when no other form fits.

| Source | Reference form | Notes |
| --- | --- | --- |
| Report or annual report by an organisation | Organisation. (Year). *Title* (Report No.). Publisher if different from the author. URL | Manual Section 10.4, including its annual-report example. |
| Filing with the U.S. Securities and Exchange Commission | Company. (Year). *Form 10-K for the fiscal year ended December 31, 2025*. U.S. Securities and Exchange Commission. URL | House adaptation of the report form; the manual gives no filing example and says to adapt the most similar category. Take the form name and reporting period from the filing's cover. Give the publisher only for a copy retrieved from EDGAR. |
| Press release | Organisation. (Year, Month Day). *Title* [Press release]. URL | Manual Section 10.4. As a house adaptation of the repository rule in Section 9.30, give U.S. Securities and Exchange Commission in the source element for a release read only as an exhibit on EDGAR; prefer the company's own copy. |
| Presentation slides, including investor presentations | Author. (Year, Month Day). *Title* [Presentation slides]. Site name if different from the author. URL | Manual Section 10.14 gives the slide form; applying it to investor presentations is a house adaptation. |
| Newspaper article | Author. (Year, Month Day). Title of article. *Newspaper Name*, page. URL | Give the page when the article has one and omit the URL for a print or research-database copy. Cite an article on a news website, such as Bloomberg or Reuters, with the webpage form (Manual Sections 10.1 and 10.16). |
| Earnings call recording | Company. (Year, Month Day). *Title* [Webcast]. URL | House adaptation of the recorded-webinar form in Manual Section 10.12. Name a quoted speaker in the text and give a time stamp. An unrecorded call is a personal communication. |
| Earnings call transcript | Provider. (Year, Month Day). *Title* [Transcript]. Site name. URL | House adaptation. The provider is the organisation named on the transcript as producing it. When none is named, make the company the author and omit a site name that repeats it. |
| Webpage | Author. (Year, Month Day). *Title*. Site name if different from the author. URL | Manual Section 10.16. Use the date that applies to the cited content, or *n.d.* |
| Data set analysed by the writer | Author. (Year). *Title* (Identifier; Version) [Data set]. Publisher. DOI or URL | Manual Section 10.9. Cite the publication instead when you take a published statistic from it. |
| Proprietary financial database, such as S&P Capital IQ or Bloomberg | Provider. (Year). *Title of the screen or export* [Data set]. Database name. Home or login URL | For an untitled screen or export, use APA's untitled-work form: Provider. (Year). [Description of the series or screen]. Database name. Home or login URL. The database name stands in roman type as the distributor element of Manual Section 10.9, and the home or login URL follows Section 9.34. Using the data set form for a database screen or export is a house adaptation. Omit a database name that repeats the provider, and add a retrieval date for content that changes. |
| Specialised software | Author. (Year). *Title* (Version x.y) [Computer software]. Publisher if different from the author. URL | Give no reference for software that is common in the field, such as Microsoft Office or a standard statistics package, or for a programming language, unless you paraphrase or quote it. Name it in the text in roman type, with its version when relevant (Manual Section 10.10). |

## Generative AI

APA's guidance on generative AI appears on the APA Style website, not in the 2020 manual. Follow the
institution's policy on whether and how AI may be used.

- Credit the company that developed the AI tool rather than citing AI output as a personal
  communication.
- Cite a tool as Company. (Year of the last update). *Tool or model name* [Large language model].
  URL of the tool. When the tool shows no update year, use the copyright year on its website or
  app. Use the bracketed description that best fits a tool that is not a chat tool, such as a
  coding agent. Add a version in parentheses only when the tool shows one.
- Cite a shared chat as Company. (Year, Month Day). *Title of chat* [Generative AI chat]. Tool or
  model name. Share URL. APA gives no form for a session without a share URL; cite the tool and give
  the relevant prompts and output in the text or an appendix.
- In the text, give the company and year, as in *(OpenAI, 2025)*.
- Describe each use where it occurs, such as in the method section or a table note, and cite the
  tool or chat there. An AI contribution statement may summarise all uses when the institution
  requests or permits one.
- Keep prompts out of the reference entry. Give a prompt that matters in the text or an appendix.
  When quoting output, state the prompt and quote the output with a citation.
- AI used only to find sources, or built into common software, needs no citation. Read and cite the
  sources it found.

Complete this branch when each cited source uses the row matching what the work is (not merely how
it was retrieved), any generative AI use is disclosed in text and credited to its developer rather
than as a personal communication, and any unresolved source form is reported.
