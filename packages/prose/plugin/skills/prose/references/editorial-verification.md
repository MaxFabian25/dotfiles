# Editorial verification

Check the requested edit against its source and purpose. Preserve meaning, claim scope, voice,
protected wording, and the requested degree of intervention. Check the changed passage in context
and repeat the affected check after a material correction.

For edits affecting a piece's overall development or rhythm, and for final manuscript preparation,
read the complete text for sense and rhythm.

For changes to voice, imagery, humour, repetition, or rhythm in an essay, talk, or personal
narrative, use [craft after editing](authored-prose.md#craft-after-editing).

## Document-level checks

For a manuscript edit, copyedit, or proofreading task, check the items the document contains and
the edit affects:

| Item | Check |
| --- | --- |
| Structure | Titles, headings, contents, navigation, and rendered order agree. |
| Displays | Illustrations and tables agree with captions, callouts, text references, and lists. |
| Notes and citations | Markers reach notes; citations match their reference-list counterparts; each cited source, at any locator given, supports the claim attributed to it. |
| Quotations | Wording and locators agree with the source. |
| Abbreviations | Forms agree with definitions and any list. |
| Definitions | Each defined term appears in the text and follows the [definition rules](terminology-selection.md#definitions). |
| Cross-references | Links and references reach their current named targets. |
| Contributors | Names and roles agree wherever the document records them. |

Prefer a stable named heading, anchor, or identifier to a spatial pointer. Use page locators when
the selected style or fixed layout needs them. Record the source and checked version when several
versions or generated outputs could be confused.

## Final manuscript handoff

When the task prepares a final manuscript, inspect the complete intended version and its generated
outputs against the approved source. Rebuild an output whose source is newer. Remove unapproved
comments, queries, tracked changes, revision marks, hidden text, and placeholders; preserve evidence
and material required by the deliverable. Proofread the rendered output after cleanup and retain a
recovery route when the handoff replaces maintained work.

Complete the edit when the requested changes and affected consistency checks are resolved. Report
an unavailable source, unrendered format, or unresolved discrepancy that limits that conclusion.
