# Multilingual source

Apply this branch to multilingual or non-English source text, translation, transliteration, or
romanisation. Apply [Source preservation](source-preservation.md) before the
metadata and presentation rules below.

## Basic rules

- Resolve an uncertain passage language or script with the author or a qualified language reviewer.
- In new prose, follow an authority for the language or established English usage.
- Record the language of each passage in the host's supported metadata. Mark each language change
  as narrowly as the host permits.
- Identify required scripts, characters, fonts, text directions, and line-breaking constraints.
  Verify them in the rendered output.
- Let the host implement encoding, fonts, bidirectional layout, and language attributes. Do not
  invent unsupported rendering syntax.
- Decide whether an unfamiliar non-English word needs italics or a gloss from audience, context,
  repetition, and authorial voice.
- Do not italicise a proper name merely because it is non-English. Avoid repeatedly glossing a term
  after readers can recognise it.
- For translation, transliteration, or romanisation, apply [Source
  text](source-text.md#translations-and-transliteration-or-romanisation).

Complete this branch when each language, script, translation, transliteration, and locale-specific
form is identified and preserved within its governed scope.
