# Indexing and cross-references

Apply this branch when a long work needs an index, embedded index, or standard keyword vocabulary.
Start by recording the intended readers and the subjects they are likely to seek.

Record the indexing terms, main headings or full entries, and cross-references. Include locators or
direct links to the text, the indexer, output version, and result.

Choose indexing terms for substantive terms and subjects that readers are likely to seek. Prefer
the author's terminology and omit incidental mentions. Place each entry where readers are most
likely to look.

Use a redirecting cross-reference for a variant, synonym, alias, or abbreviation only when readers
might otherwise miss the full entry. It must lead directly there. Use a related-item cross-reference
only for additional information.

Give each entry a locator or direct link. Link an embedded index term to the point that it describes.
In electronic formats, link each cross-reference to its target.

An automatically generated concordance is not an index. The indexer selects and reviews the terms,
main entries, cross-references, locators, and direct links.

Let the host govern ordering, alphabetisation, layout, and typography. Check every locator, direct
link, and cross-reference against the latest rendered output. Repeat the review after a material
edit.

Complete this branch when the indexer has checked every term, entry, cross-reference, locator, and
link against the latest rendered output.
