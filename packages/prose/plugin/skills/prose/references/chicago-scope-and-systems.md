# Chicago scope and systems

Select this branch only from an explicit user, publisher, journal, or project requirement with a
stated scope.

Use authority `AUTH-CMOS-18` from [source provenance](source-manifest.md) only within the recorded
Chicago scope. Outside that scope, treat it as supporting editorial literature.

## Scope

Before applying a Chicago rule, record:

- the selecting authority and exact requirement
- the scope: editorial mechanics, quotations, citations, or a stated combination
- governing publisher or journal instructions and their edition, version, or date
- every overlapping requirement and its resolved precedence
- the citation system for any selected citation scope

Do not extend a Chicago selection from one scope to another. Apply only recorded rules from this
branch, a linked operative module, or an authorised copy of the selected edition.

For Chicago quotations, apply [Chicago quotation scope](source-text.md#chicago-quotation-scope).
For Chicago mechanics, apply the Chicago rules in [Select a convention](number-forms.md#select-a-convention)
and [Abbreviations](terminology-selection.md#abbreviations). For Chicago citations, use the system
selected below.

For an unlisted Chicago convention, consult an authorised copy of the selected edition. Otherwise,
preserve the existing treatment and record the convention as unverified. Claim conformity only to
the selected rules.

## Chicago-style source citations

When the Chicago scope includes citations, select exactly one system for the work before drafting:

| System | Citation forms |
| --- | --- |
| [Notes and bibliography](chicago-notes-and-bibliography.md) | Numbered source notes and a recorded bibliography decision. |
| [Author-date](chicago-author-date.md) | Parenthetical author–year citations and a corresponding reference list. |

- Use the system named by the governing requirement or by publisher or journal instructions. When
  none names a system, ask the user to choose one and record the choice.
- Do not select a system solely from the work's discipline.
- Do not combine the two citation systems within one work.
- Explanatory notes may accompany author-date when the governing requirement permits them.
- Do not use those notes as a second notes and bibliography system.

## APA boundary

When both APA and Chicago are explicitly selected, record each scope before writing. Apply the
systems independently where their scopes do not overlap.

When Chicago controls citations, APA citation and reference-list forms do not control that scope.
When APA controls another scope, Chicago does not displace it. Stop if two controlling requirements
remain incompatible.

Complete this branch when recorded Chicago scope, citation system, editorial mechanics,
quotations, and selected source branches are internally consistent.
