# Chicago review sources

Apply this branch when a Chicago citation concerns a review. Use [Chicago source forms](chicago-source-forms.md)
for shared citation-form, no-author, and locator mechanics.

Record the named reviewer, the reviewed work and who is responsible for it, the hosting periodical,
and the issue details. When applicable, add the review title, performance details, locator, access
information, and treatment for an unsigned review.

## Reviews

- Lead with the reviewer when named. Add the review title when present.
- Identify the reviewed work and its author, editor, director, performer, or other relevant person.
- For a performance review, add only details needed to identify the subject. These may include the
  director, sponsor, performer, venue, place, or performance date.
- Finish the entry in the form required for the hosting journal, magazine, newspaper, or news site.
- Alphabetise a bibliography entry under the reviewer.

Complete this branch when each review has one type, an identified host, and complete fields.
