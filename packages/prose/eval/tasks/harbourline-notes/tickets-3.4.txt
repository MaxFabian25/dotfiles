HBL-2201 (feature): Add `harbourctl export --format json` so admins can dump the full lease table
as JSON. Requested by several customers who feed leases into their CMDB. Previously only CSV.

HBL-2215 (enhancement): Raise default max concurrent zone transfers from 10 to 50. Big sites were
queueing AXFRs for minutes after a restart.

HBL-2187 (bug): Race in lease renewal when two relays forward the same DHCPREQUEST within ~5 ms.
Both got ACKed with different addresses, so the client ended up with two leases and the pool ran
dry faster. Fixed by taking the per-client lock before the pool lookup. Also added an
`address_in_use_check` option (on by default) that pings an address before offering it.

HBL-2193 (bug): Web console showed reservation timestamps in UTC even when the browser locale had
another zone. Now converts to the browser's zone.

HBL-2230 (known issue): If you upgrade from 3.2 directly to 3.4, DNSSEC keys generated with the old
`keytool` are not picked up and signed zones fail validation. Workaround: run
`harbourctl dnssec rekey --all` after the upgrade, or go 3.2 -> 3.3 -> 3.4. Proper fix targeted for
3.5 in March.

HBL-2241 (known issue): On hosts with more than 64 network interfaces, the interface picker in the
web console is cut off and the extra interfaces can't be selected. No workaround found yet; eng
thinks it'll be fixed in 3.4.1.

HBL-2160 (deprecation): The `legacy_ddns` config section is deprecated and will be removed in 4.0.
Use the `ddns` section instead.
