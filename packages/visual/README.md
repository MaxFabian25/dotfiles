# Visual plugin

Owned visual explanation and pull-request walkthrough plugin for Codex, Claude Code, and Antigravity.

## Skills

- **`show-me`** (model-invoked): Explains code, architecture, state machines, data, and tradeoffs with concise text views or compiled self-contained interactive HTML visuals.
- **`visual-pr`** (explicit-only): Generates either an interactive HTML pull-request walkthrough canvas or a concise GitHub Markdown pull-request description.

## Design system and tooling

- `plugin/kit/tokens.css`: WCAG-audited OKLCH themes (`nova` default, `vega`, `maia`), explicit `Geist` / `Geist Mono` / `Geist Serif` font stacks, and analytical CSS `linear(...)` spring easing generated by `scripts/sync_tokens.ts` from `effect-ui-extra`.
- `plugin/kit/components.css`: Shared typography, surface, responsive flow, chart, and native `<details>` / `popover="auto"` component styles.
- `plugin/kit/runtime/`: Opt-in zero-dependency JS modules (`core.js`, `stepper.js`, `diagram.js`, `diff.js`).
- `plugin/scripts/build.py`: Compiles an HTML body fragment plus requested runtime modules and optional diff JSON into one self-contained HTML file.
- `plugin/scripts/check.py`: Verifies static rules (Geist, no external URLs, T3 transparent canvas, no `vh`, accessible controls, SVG labels) and optional browser metrics (`--browser`).
