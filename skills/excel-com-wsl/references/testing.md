# Proving a change to the scripts with test_fixtures.py

## Running it and what it keeps

`EVIDENCE_DIR` keeps each job's result as `NAME.json`, what it printed as `NAME.out` and its stderr as `NAME.stderr`, because a job that ends without a result says why on stderr only. The `no-value` case, a job that `excel.py` turns away for a `--set` with no `=`, showed on 13 November 2026 that the message reaches `no-value.stderr`. That job starts no Excel, so the check `each job through real Excel keeps its stderr in the evidence folder` fails when such a job has no `NAME.stderr` ([incidents](../references/incidents.md)). A full run took about 3 to 12 minutes on 12 November 2026, and a restart of the agent app cancelled such runs in the shell tool's foreground, so run each as a job of its own name, from the skill folder: `WSL_INTEROP=/run/WSL/1_interop agent-job start excel-fixtures-1 --env WSL_INTEROP -- python3 -I scripts/test_fixtures.py EVIDENCE_DIR`, with the interop setting that the `work-across-tailscale-machines` skill gives a unit that starts Windows programs, then `agent-job wait excel-fixtures-1 --timeout 1200` in your shell tool's background mode, with the next number for the next run. With `--no-excel` after `EVIDENCE_DIR` it runs only the cases that start no Excel, which takes under a minute and is enough while you change the error scan's handling of an answer; the full run is still the proof. Run it after any change to a script, because "a formula calculated" passes while the cases below still fail.

## The cases

Its busy case runs `scripts/test-busy.ps1` beside the job, which finds the job's Excel through the job's open workbook and its process ID and starts no Excel of its own. Whether that helper's rebuilds land is a matter of timing, so the case runs the job up to three times, and prints a `NOTE` line when none landed on the reopened copy. The helper's shutdown rule and the check `no job's Excel crashed`, which reads Windows' Application log for the suite's own Excel processes, are described in [references/quit-order.md](../references/quit-order.md). The reads that Excel refuses are tested without Excel, by `scripts/test-read-guard.ps1`.
