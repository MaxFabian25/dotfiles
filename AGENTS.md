## Paired checkout

The paired private checkout is the sibling `dotfiles-private`, or `private` beside this `public` folder in a `release.py` worktree.

## Agent skills

### Issue tracker

Issues live in the GitHub Issues of `MaxFabian25/dotfiles-private`, not this public repository's. See `docs/agents/issue-tracker.md`.

### Triage labels

None: the private tracker is a flat backlog. `/triage`, run by name, uses the five canonical roles there. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context, shared with the private repository; keep private material out of this repository. See `docs/agents/domain.md`.
